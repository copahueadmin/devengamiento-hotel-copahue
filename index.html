Copias de seguridad y restauración

Todas las noches a las 23:59 hs el sistema envía por correo a copahueadmin@gmail.com un archivo .zip con todos los datos (movimientos, historial, configuración, usuarios y órdenes de pago). Ese mismo archivo sirve para restaurar el sistema si algo falla.

Descargar una copia ahora
Genera el .zip con el estado actual y lo guarda en tu computadora.
Probar el envío de correos
Manda un correo de prueba (marcado como automático) a la dirección que escribas, para comprobar que el envío funciona. Si falla, abajo aparece el motivo.
Restaurar desde una copia
Elegí el .zip que llegó por correo. Se reemplazan todos los datos actuales por los de la copia (lo que se cargó después de esa copia se pierde). Antes de restaurar se descarga automáticamente una copia del estado actual, por si hay que volver atrás.
